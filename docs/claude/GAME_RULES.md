# 현재 코드의 게임 규칙

이 문서는 사용자 업로드 작업본을 읽어 정리한 구현 설명이다. 실제 2026 LCK 로스터·패치 규정이 정확하다는 검증은 하지 않았다.

## 유지해야 할 사용자 의도
- 웹과 모바일에서 같은 게임을 플레이한다.
- 실제 롤 챔피언을 사용한다.
- 우리 팀의 밴픽은 사용자가 직접 결정한다.
- 선수별 자주 쓰는 챔피언/숙련도, 메타가 경기 능력에 영향을 준다.
- 중계는 실제 선택한 챔피언으로 상황을 해설한다.
- 대화가 끊겨도 다른 코딩 도구에서 소스와 기록을 이어간다.

## 상태 흐름
PLAN → train → PREP → startDraft → DRAFT → draftPick 반복 → 완료 후 draftSwap 선택 → play → RECAP → continue → PREP 또는 MATCH_END → advance.
대회 종료는 SPLIT_END/WORLD_END/OFFSEASON을 거쳐 다음 대회·시즌으로 이동한다.

## 직접 밴픽
- DRAFT_ORDER 20턴, 양 팀 5밴·5픽. 밴 B/R 3번 교대, 픽 B/R/R/B/B/R, 밴 R/B/R/B, 픽 R/B/B/R.
- 첫 세트 A가 블루, 이후 직전 패배 팀이 블루.
- `startDraft`로 시작. `draftPick {champ}`로 현재 밴 또는 픽을 확정. AI는 상대 차례만 처리.
- 모든 챔피언을 자유롭게 픽한 뒤 5명 역할 최적 배정을 한다. `draftSwap {from,to}`는 0~4 인덱스로 두 포지션을 교환한다.
- 지정 role 또는 flex는 무패널티. 다른 역할은 모든 스탯 −6.
- `draftReset`은 현 세트 밴픽 재시작. 현재 버전에서 허용된 게임 행동이다.
- 세트마다 풀 초기화. 피어리스 미적용.

## 데이터와 숙련도
`lib/champions.ts`: 140개 ID/이름, TOP30/JGL29/MID30/ADC25/SUP26. 타입 AD/AP/혼합, 태그 engage/peel/poke/scale, flex 배열.
`Player.mastery`: `{champ,level,xp}[]`. 기본 포지션의 4~5개 챔피언 풀로 시작하고 등록 최대 8개. 초기 숙련은 선수 능력대에 따라 Lv1~3, 최대 Lv4. 100XP마다 1레벨 증가하고 최대 레벨의 XP는 0으로 정리한다.

- 능력 보너스: `masteryLevel × 2 + (시즌 메타면 2)` → 주요 2능력에 적용, 최대 +10.
- 주요 능력: TOP LNE/MEC, JGL OBJ/VIS, MID LNE/CAR, ADC TF/MEC, SUP TF/VIS.
- 경기 보정 = 기본 스탯 + 당일 컨디션 − 오프롤 패널티 + 주요 능력 보너스. 1~105 제한.
- 경기 숙련 XP는 **매치 종료 시** 각 세트 참가자에게 반영: 기본4 + 매치 승리2 + 해당 세트 POG3, 코치 레벨당 10% 증가 후 반올림.
- 챔피언 특훈은 기본28XP × 코치 성장 배율. 신챔피언 목표 처리에는 확인된 개선점이 있다(BACKLOG).
- 시즌 메타는 seed/season으로 포지션별 2~3종을 뽑고 새 시즌에 바뀐다. 실제 라이브 통계 연동이 아니다.

## 경기와 중계
최대9개 이벤트. TOP/MID/BOT, 상단/하단 오브젝트, 중후반 교전과 기지 결전. 전력차·누적 우위로 확률을 구하며 5%~95% 제한. 후반 교전 압박3회 또는 마지막 이벤트로 승자가 결정된다.
중계는 `narrate`에서 실제 픽 이름과 한국어 조사를 조합한다. `goldA/goldB`는 연출용 증분값이며 승부 파워 계산에 들어가지 않는다. 현재 문구의 킬 수·스킬 적중은 독립 전투 상태로 저장되지 않는다.

## 다른 경영 시스템
국내10팀·해외13팀, 정규18라운드 Bo3, 국내 플레이오프 Bo5, 미드시즌8팀, 월드16팀 스위스→8강. FA/재계약/트레이드, 코치/분석가/심리 코치, 노화·신인과 장기 커리어를 유지한다.
화면 표시명은 실존 팀·선수 데이터지만, 기본 OVR·리그 규칙·경제는 게임 설계값이다.
