# 중계 화면 후속 개선

2026-09-14. 사용자 요청에 따라 Git 작업과 배포를 하지 않음.

## 실제 변경
- posAt은 다음 키프레임 이전에 교전·사망·부활 상태를 미리 노출하지 않는다. 정확한 타임스탬프에만 전환한다.
- 화면의 KDA는 이미 재생한 kill beats의 실제 killer/victim/assists에서 집계한다. 10인 선수명·챔피언·역할·현재 행동 표시와 선수 상세 연결을 추가했다.
- 겹친 아이콘의 원형 흩뿌리기를 역할별 진형으로 교체했다. 진입 조합과 보호 조합의 서포터 위치를 달리하며, 도착 후 0.45초 보간으로 펼쳐지고 전투 이탈 때 원래 경로로 합쳐진다. 이는 표시 오프셋으로, 실거리·교전 판정·피해량·이동 경로를 바꾸지 않는다.
- 부모 중계/골드 그래프는 현재 사건 번호가 아닌 실제 완료한 사건 수로 공개한다. 완료된 사건만 되돌아보기 목록에 표시한다.
- 끝으로 이동 시 결과 열기, 종료 후 재생 시 재시작, 종료 후 되감기 시 결과 감추기, 종료 콜백 중복 방지를 수정했다.

## 검증
replay.test 기존 스위트 통과. broadcast.test 신규 50경기에서 원본 전투 기록과 최종 KDA 독립 비교, 첫 킬 직전 기록 미노출, 되감기 초기화, 완료 사건 수, 사망/합류 경계, 진형 보간, 끝/되감기 전환을 검증한다. management, TypeScript, build도 실행. 상세 로그는 validation-continuation 참조.

## 미완료
브라우저에서 실제 클릭·애니메이션·모바일 레이아웃 확인은 이번에도 완료하지 못했다. 단위 테스트가 브라우저 인수를 대신하지 않는다. 챔피언별 특성 검수, 더 세밀한 운영/스킬 모델과 감독 개입은 별도 후속 작업이며 이번 변경으로 완료됐다고 하지 않는다. 승패 엔진/조합 공식/세이브 형식은 변경하지 않았다.

## 다음 첫 행동
실행 가능한 브라우저에서 끝→되감기→재생→다음 사건 흐름을 PC/모바일로 인수하고, 챔피언 특성 모델을 기존 태그와 분리해 검수한다.
