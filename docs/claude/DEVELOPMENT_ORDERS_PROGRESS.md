**목표:** "한 번의 play로 simulateSet을 끝까지 계산"하는 구조를 버튼만 얹어 흉내 내지 말고, 오브젝트 준비 구간에서 실제로 한 번 멈춰 감독 지시("싸움 준비/반대편 이득/정비")를 받아 이후 사건에만 반영하는 첫 완결 기능을 만든다.

**사용자에게 달라진 경험:** 밴픽을 마치고 "세트 경기 시작"을 누르면 이제 세트가 즉시 끝나지 않는다. 라인전 3사건(탑·미드·바텀) 결과를 먼저 보여주고, 그 결과를 바탕으로 오브젝트 구간 작전을 셋 중 하나로 고르게 한다: **싸움 준비**(다음 한타 유리, 오브젝트 확보엔 안 도움)·**반대편 이득**(오브젝트 확보 유리, 한타 준비는 덜 됨)·**정비**(중립, 기존과 동일). 고른 뒤에만 세트가 끝까지 계산되어 리캡으로 넘어간다. 방송 화면(재생)은 기존과 동일하게 동작한다 — 사건 자체가 더 생겼을 뿐 재생 방식은 안 바뀐다.

## F07 — 사람이 읽을 수 있는 AI 밴픽 · 상대 응수 1단계 탐색 신설 (2026-09-15)

**목표:** 위협 제거 밴·핵심 조합 선점·상대 응수·flex 실제 배치·미완성 조합 보완을 판단하는 AI 밴픽. 확정 안 된 상대 픽을 미리 읽지 않는다. 추천·자동 픽이 같은 합법성 검사를 쓴다.

**구현:**
- `lib/game.ts`에 `bestOpponentReply(g,ds)` 신설 — 순수 함수, rng 미소비. "만약 지금까지의 실제 확정 상태에서 상대가 다음 합법 수 중 자신에게 가장 좋은 것을 고른다면 그 이득이 얼마인가"를 `draftFitScore`(이미 있던 함수, 순수·결정적)로 측정한다. **재귀 없음(정확히 1단계)**, 합법성은 `legalDraftCandidates`를 그대로 재사용 — 추천/자동픽/이 탐색이 전부 같은 검사를 쓴다.
- `aiPick`: 기존 점수 계산(불변)으로 전체 후보를 1차 채점 → 상위 5개(시간 예산)만 각각 "이걸 고른 가상 상태"를 만들어(`structuredClone`) `bestOpponentReply`로 응수 페널티를 적용 → 페널티 반영 후 최고점을 최종 선택. 노이즈(`rng()*noise`)는 기존 1차 채점에서만 쓰고 탐색 자체는 rng를 소비하지 않는다 — **기존 draft rng 스트림 호출 횟수·순서 불변**(표시 수정 원칙과 동일한 이유로 결과-영향 최소화).
- **성능 안전장치**: 상대 응수 탐색은 **사용자 실제 매치**(`m.a===g.teamId||m.b===g.teamId`)에서만 돈다. 처음 구현해 전체 테스트를 돌렸을 때 `autoMatch`(사용자가 보지 않는 리그 전체 자동 진행, 시즌당 수백 개 드래프트)까지 비싸게 만들어 `engine.test.mjs`가 눈에 띄게 느려지는 것을 실측으로 발견 — 배경 시뮬레이션 품질은 F07의 목적이 아니므로 사용자 매치로 범위를 좁혔다(회귀 없음, `scored[0]`는 안정 정렬로 기존 "첫 최고점"과 동일한 타이브레이크).

**변경 파일:** `lib/game.ts`(`bestOpponentReply` 신설, `aiPick` 상위 5개 후보에 응수 탐색 적용 + 사용자 매치 한정 가드).
