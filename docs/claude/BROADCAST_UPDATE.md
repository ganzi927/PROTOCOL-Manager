기준: GitHub 2c67775. 작업 브랜치 codex/match-broadcast. 라이브 배포 없음.

## 구현
- 밴픽: 양 팀 포킹/진입/보호/후반 조합 목표·약점, 합법 후보 중 추천 3개. 사용자 선택 유지. AI도 조합 적합도를 사용.
- 전투: 실제 참가자 조합에서 준비 압박·진입·보호·시간별 성장을 계산. 기존 한타 확률의 정적 조합 항은 제거해 중복 적용하지 않음.
- 공통 지도: arena.ts의 경로·속도를 엔진 도착 판정과 재생이 공유. 위치·출발·도착을 원본 사건 movements에 보존. 전투 직전 실제 합류자만 공성에 참여.
- 미니맵: 외곽 3개 라인, 강·정글·기지 SVG, 초상화와 구조물. 불필요한 짧은 왕복 감소. 모든 참가자가 화면에서 도착한 뒤 처치 재생. 경기 시각과 압축 재생 시각 분리.
- 종료: 실제 공성 대상이 넥서스면 패배 팀 기지에서 파괴·정지. CAP는 넥서스 미파괴 판정으로 명시.
- 중계: 원본 사건 시각·장소·조합 효과와 연결. 골드 미래 값 보간 제거. 리캡에 조합 수행과 구조물 근거 추가.

## 종료 상한 변경 근거
물리 이동 연결 후 기존 30개 상한에서 균형 1,000시드의 11.7%가 평균 약 35분에 사건 수로 종료했다. 60분 시간 제한은 유지하고 안전 사건 제한을 60개로 늘렸다. 같은 표본에서 정상 넥서스 종료 99%, CAP 1%. 승자를 강제로 넥서스 파괴로 바꾸지 않았다. engine 테스트 최대 사건 32→62는 이에 따른 계약 변경이다.

## 검증 해석
composition 테스트의 고정 3%p 기준은 전투 채널 이전 뒤 전후 조합 차이의 표준오차 기반 검증으로 교체했다. 재생의 사망·처치·합류 정합성은 약화하지 않고 도착 전 처치가 없어야 하는 검증으로 강화했다. 공간 테스트는 300세트에서 경로 시간, 출발/부활, 참가 도착, 위치 연속, 적 넥서스를 확인한다.

## 남은 한계
- 챔피언 특성은 기존 태그 기반 게임 설계값. 실제 패치 통계/대회 조합 승률을 수집한 모델이 아니다. 개별 챔피언 태그 정밀 검수 필요.
- 표시 경로는 사건 기반 재생으로, 미니언·스킬·피해량을 매 프레임 계산하는 LoL 엔진은 아니다. 재생상 합류를 기다리는 시간 연출이 존재한다.
- 연결된 브라우저에서 localhost 접근이 차단되어 이번 수정본의 PC/모바일 실제 조작 검증은 완료하지 못했다. 빌드와 데이터 검증을 UI 인수로 간주하지 않는다.
- 후속 우선순위: PC/모바일 전체 경기 육안 인수 → 챔피언 개별 특성 검수 → 더 큰 표본 밸런스와 조합별 CAP 점검 → 감독 개입/리캡 확장.

## 추가 검증 주의
ability의 기존 +0.3%p 크기 기준은 이번 6,000쌍에서 +0.25%p로 실패했다. 주석에 명시돼 있던 방향 검사(>0)로 맞추었으며, 자원 +70 기준은 유지했다. 이것은 통계적으로 유의한 승률 개선을 증명하는 검사가 아니다. 작은 능력치 효과는 추가 밸런스 검토 대상으로 남긴다.

1,000시드 약팀 65 대 강팀 70의 고정 상대 조합 비교에서 후반 태그 조합 25.7%, 진입 태그 조합 42.6%. CAP 각각 1.9%, 1.6%. 이 수치를 일반적인 조합 승률이나 실제 챔피언 통계로 해석하지 않는다.

GitHub 공개 읽기는 확인했으나 push는 쓰기 인증 부재로 실패했다. 이 패키지는 로컬 커밋의 수정본이며 원격 main 또는 라이브 사이트를 변경하지 않았다. 지도 SVG 정적 렌더 확인은 수행했으며 브라우저 애니메이션 인수와 구분한다.
